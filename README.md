# HARDFIX

Сайт сервисного центра по ремонту электроники: смартфоны, ноутбуки, компьютеры, планшеты, консоли.

- Статический сайт: один `index.html`, без сборки
- 3D-разборы телефона и ноутбука на Three.js r128 (cdnjs)
- Калькулятор стоимости, трекер статуса заказа (демо-данные), форма заявки (без бэкенда)

## Деплой

Vercel: Framework Preset — **Other**, без build-команды, output — корень репозитория.

## Перед запуском

- Заменить адрес, телефоны, e-mail и имена мастеров (сейчас заглушки)
- Подключить отправку формы (например, вебхук Make/n8n)
- Добавить страницы Impressum и Datenschutz
